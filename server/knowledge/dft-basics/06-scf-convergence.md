# SCF 收敛技巧

## SCF 自洽迭代原理

SCF（Self-Consistent Field）是 DFT 计算的核心过程。其基本流程：
1. 猜一个初始电子密度 ρ₀
2. 用 ρ₀ 构建有效势 V_eff
3. 求解 Kohn-Sham 方程，得到新的波函数和密度 ρ_new
4. 将 ρ_new 与 ρ_old 混合，得到更新的密度
5. 重复 2-4，直到输入输出密度的差异（收敛阈值 conv_thr）小于设定值

## QE 中的关键收敛参数

### conv_thr（收敛阈值）
```
&ELECTRONS
    conv_thr = 1.0d-8   ! 能量收敛精度 (Ry)
/
```
- 默认值：1.0d-6
- 结构优化推荐：1.0d-8 ~ 1.0d-10（需要准确的力）
- 单点能计算：1.0d-6 ~ 1.0d-8
- 值越小越精确，但迭代步数越多

### mixing_beta（混合系数）
```
&ELECTRONS
    mixing_beta = 0.3   ! 新旧密度的混合比例
/
```
- 范围：0.0 ~ 1.0
- 默认：0.7
- **难收敛时减小**：0.1 ~ 0.3（更保守的更新）
- 金属/磁性体系：推荐 0.1 ~ 0.3
- 绝缘体/半导体：0.5 ~ 0.7 通常足够

### mixing_mode（混合模式）
- `plain`：简单线性混合（默认）
- `TF`：Thomas-Fermi 筛选混合
- `local-TF`：局域 Thomas-Fermi 混合（推荐用于表面/界面等非均匀体系）

### electron_maxstep（最大迭代步数）
- 默认：100
- 如果 100 步不收敛，通常说明参数有问题
- 增大此值到 200-500 可能有帮助，但应优先排查参数

### diagonalization（对角化方法）
- `david`：Davidson 方法（默认，推荐）
- `cg`：共轭梯度法（大体系或内存受限时使用）

## 常见不收敛原因及解决方案

### 原因 1：mixing_beta 太大
- **症状**：能量在几个值之间振荡
- **解决**：减小 mixing_beta 到 0.1-0.3

### 原因 2：K 点太稀（金属体系）
- **症状**：能量缓慢下降但不收敛
- **解决**：增加 K 点密度，添加 smearing

### 原因 3：初始结构不合理
- **症状**：第一步能量就很高，然后崩溃
- **解决**：检查原子坐标，确保没有原子重叠

### 原因 4：截断能不足
- **症状**：收敛到错误的能量值
- **解决**：增大 ecutwfc

### 原因 5：磁性初始猜测不对
- **症状**：自旋极化计算不收敛
- **解决**：设置合理的 starting_magnetization

## 加速收敛的进阶技巧

1. **使用 Broyden 混合**：`mixing_mode = 'plain'`, `mixing_ndim = 8`（默认就是 Broyden）
2. **smearing**：金属体系必须使用（见 smearing 专题文档）
3. **分步计算**：先用低精度（conv_thr=1d-4）快速收敛，再用高精度精修
4. **restart**：将 `startingpot = 'file'` 从已收敛的类似计算重启
