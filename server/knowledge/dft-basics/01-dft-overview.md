# 密度泛函理论（DFT）方法概述

## 什么是 DFT

密度泛函理论（Density Functional Theory, DFT）是一种基于量子力学的电子结构计算方法。其核心思想是：体系的基态性质可以完全由电子密度 ρ(r) 唯一决定，而不需要求解复杂的多体薛定谔方程。

DFT 是目前材料科学和凝聚态物理中使用最广泛的第一性原理计算方法，能够在不依赖经验参数的情况下预测材料的电子结构、力学性质、光学性质等。

## Kohn-Sham 方程

DFT 的实际计算基于 Kohn-Sham（KS）方程框架。核心思想是将相互作用的多电子问题映射到一个等效的无相互作用体系：

- 将总能量分解为：动能 + 外势能 + 库仑能 + 交换关联能
- 交换关联能（Exc）是唯一需要近似处理的部分
- 通过自洽场（SCF）迭代求解 KS 方程

## DFT 能做什么

DFT 可以计算的物理量包括：

- **总能量**：体系的基态总能量
- **力与应力**：原子受力和晶格应力（用于结构优化）
- **电子能带结构**：电子能量与晶体动量的关系
- **态密度（DOS）**：单位能量间隔内的电子态数目
- **电荷密度分布**：电子在空间中的分布
- **磁性**：磁矩、自旋极化态密度
- **声子谱**：晶格振动模式与频率
- **光学性质**：介电函数、吸收谱

## DFT 的局限性

- **带隙低估**：标准 DFT（LDA/GGA）严重低估半导体和绝缘体的带隙
- **强关联体系**：对含 d/f 电子的强关联体系描述不佳
- **范德华力**：标准泛函缺乏对色散力的描述
- **激发态**：DFT 本质上是基态理论，激发态需要其他方法（如 TDDFT、GW）
- **计算成本**：随体系尺寸的三次方增长（O(N³)）
