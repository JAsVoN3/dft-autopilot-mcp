# 交换关联泛函选择指南

## 泛函分类（Jacob's Ladder）

交换关联泛函按精度和计算成本递增，分为五个层级（Jacob's Ladder）：

### 第一层：LDA（局域密度近似）
- **代表**：PZ, PW, VWN
- **原理**：假设交换关联能只依赖于局域电子密度
- **适用**：简单金属的结构参数（但键长通常偏短 1-3%）
- **不推荐**：几乎所有现代计算都不再推荐使用 LDA

### 第二层：GGA（广义梯度近似）
- **代表**：PBE, PBEsol, RPBE, BLYP
- **原理**：除了局域密度，还考虑密度梯度
- **计算成本**：与 LDA 几乎相同
- **推荐程度**：⭐⭐⭐⭐⭐（最常用的默认选择）

### 第三层：meta-GGA
- **代表**：SCAN, r2SCAN, TPSS
- **原理**：额外考虑动能密度
- **适用**：需要更高精度时。r2SCAN 是目前最推荐的 meta-GGA
- **注意**：QE 中需要特别设置，计算成本略高于 GGA

### 第四层：杂化泛函
- **代表**：HSE06, PBE0, B3LYP
- **原理**：混合一部分精确交换（Hartree-Fock）
- **适用**：需要准确带隙值的半导体/绝缘体计算
- **注意**：计算成本是 GGA 的 10-100 倍，QE 中使用 HSE06 需要特殊编译

### 第五层：RPA 及更高
- 通常不在标准 DFT 框架内使用

## 常用泛函推荐表

| 场景 | 推荐泛函 | QE 中的设置 |
|------|---------|-------------|
| **通用固体计算**（默认首选） | PBE | `input_dft = 'PBE'` |
| **晶格常数优化** | PBEsol | `input_dft = 'PBEsol'` |
| **准确带隙** | HSE06 | 需要 `pw.x` 特殊编译 |
| **催化反应** | RPBE 或 BEEF-vdW | `input_dft = 'RPBE'` |
| **有机分子/分子晶体** | PBE + DFT-D3 | `vdw_corr = 'DFT-D3'` |
| **层状材料（范德华）** | PBE + vdW-DF | `input_dft = 'vdw-df2-b86r'` |
| **强关联体系（d/f 电子）** | PBE + U | `lda_plus_u = .true.` |
| **磁性体系** | PBE（自旋极化） | `nspin = 2` |

## QE 中设置泛函的方法

```
&SYSTEM
    ! 方法1：直接指定泛函（覆盖赝势中的默认值）
    input_dft = 'PBE'
    
    ! 方法2：使用赝势自带的泛函（推荐，不需要额外设置）
    ! 赝势文件名中通常包含泛函信息，如 Si.pbe-n-rrkjus_psl.1.0.0.UPF
/
```

## 关键注意事项

1. **泛函与赝势必须匹配**：使用 PBE 赝势时必须使用 PBE 泛函，不可混用
2. **PBE 是最安全的默认选择**：除非有特殊需求，首选 PBE
3. **PBEsol 更适合晶格参数**：如果关注晶格常数精度，用 PBEsol
4. **范德华修正**：层状材料（石墨烯、MoS₂等）和分子晶体必须加范德华修正
5. **杂化泛函成本极高**：HSE06 的计算量是 PBE 的 10-100 倍，MVP 阶段避免使用
