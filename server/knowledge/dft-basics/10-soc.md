# 自旋轨道耦合（SOC）

## 何时需要 SOC

自旋轨道耦合在以下场景中不可忽略：
- 重元素体系（5d 过渡金属如 Pt, Au, W; 6p 如 Bi, Pb）
- 拓扑绝缘体（Bi₂Se₃, Bi₂Te₃）
- 拓扑半金属（Weyl/Dirac 半金属）
- Rashba 效应研究
- 磁晶各向异性能计算
- 精确能带结构（特别是带交叉点附近）

## QE 中的 SOC 设置

```
&SYSTEM
    noncolin = .true.        ! 非共线磁性（SOC 必须开启）
    lspinorb = .true.        ! 开启自旋轨道耦合
/
```

### 关键注意事项
1. **赝势要求**：必须使用包含完整相对论效应的赝势（全相对论赝势）
   - 文件名中通常包含 `rel` 标识
   - 例如：`Bi.pbe-dn-kjpaw_psl.1.0.0.UPF`（需要 rel 版本）
2. **计算成本**：SOC 使波函数变为旋量（spinor），内存和时间大约翻倍
3. **K 点**：SOC 破坏时间反演对称性（如有磁性），K 点对称性降低

## 轻元素是否需要 SOC

对于轻元素（原子序数 Z < 30），SOC 通常影响极小（< 10 meV），可以安全忽略。重元素（Z > 50）通常需要考虑 SOC。

## 实用建议

1. 先不加 SOC 做结构优化和初步分析
2. 在优化后的结构上加 SOC 做精确电子结构计算
3. SOC + 杂化泛函的组合计算量极大，MVP 阶段不推荐
