# DFT+U 方法

## 为什么需要 DFT+U

标准 DFT（LDA/GGA）对含局域化 d 或 f 电子的强关联体系描述不佳：
- 带隙严重低估（甚至预测为金属，如 NiO、FeO）
- 磁矩偏小
- 电子结构定性错误

DFT+U 通过在局域化轨道上加一个 Hubbard U 修正项来改善这些问题。

## QE 中的 DFT+U 设置

```
&SYSTEM
    lda_plus_u = .true.
    Hubbard_U(1) = 4.0    ! 第1种原子的 U 值 (eV)
/
```

### 各元素常用 U 值参考

| 元素 | 轨道 | 推荐 U (eV) | 应用体系 |
|------|------|------------|---------|
| Fe (3d) | d | 3.0 - 5.0 | FeO, Fe₂O₃, FeS₂ |
| Co (3d) | d | 3.0 - 5.0 | CoO, LiCoO₂ |
| Ni (3d) | d | 5.0 - 7.0 | NiO |
| Mn (3d) | d | 3.5 - 5.0 | MnO, LiMnO₂ |
| Cu (3d) | d | 4.0 - 7.0 | CuO, Cu₂O |
| Ti (3d) | d | 2.0 - 4.0 | TiO₂ |
| V (3d) | d | 3.0 - 4.0 | VO₂ |
| Ce (4f) | f | 4.0 - 6.0 | CeO₂ |

## U 值确定方法

### 方法1：线性响应（推荐）
使用 QE 的 `hp.x` 程序从第一性原理计算 U 值，无需经验参数。

### 方法2：文献参考
从已发表的 DFT+U 研究中查找同类体系使用的 U 值。

### 方法3：拟合实验值
调整 U 值使计算的带隙或磁矩与实验值接近。

## 注意事项

1. **U 值不可跨体系迁移**：不同化学环境中的 U 值可能不同
2. **DFT+U 不是万能的**：对于弱关联体系（如 Al, Cu 金属态），不需要加 U
3. **结合自旋极化**：DFT+U 通常需要与 `nspin = 2` 配合使用
4. **几何优化注意**：DFT+U 可能改变能量面形状，影响优化路径
