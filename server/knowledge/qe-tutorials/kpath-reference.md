# 高对称 K 点路径参考

> 参考：W. Setyawan and S. Curtarolo, Comp. Mat. Sci. 49, 299 (2010)

能带结构计算需要沿布里渊区的高对称路径进行。不同晶系的高对称点和推荐路径如下。

## FCC（面心立方）
如：Cu, Al, Si (diamond), GaAs (zincblende)

高对称点：
- Γ = (0, 0, 0)
- X = (0.5, 0, 0.5)
- W = (0.5, 0.25, 0.75)
- K = (0.375, 0.375, 0.75)
- L = (0.5, 0.5, 0.5)
- U = (0.625, 0.25, 0.625)

推荐路径：Γ-X-W-K-Γ-L-U-W-L-K

QE 输入示例（crystal_b 坐标）：
```
K_POINTS {crystal_b}
5
0.000 0.000 0.000  30  ! Gamma
0.500 0.000 0.500  30  ! X
0.500 0.250 0.750  30  ! W
0.375 0.375 0.750  30  ! K
0.000 0.000 0.000  30  ! Gamma
0.500 0.500 0.500  1   ! L
```

## BCC（体心立方）
如：Fe, W, Cr, Na

高对称点：
- Γ = (0, 0, 0)
- H = (0.5, -0.5, 0.5)
- P = (0.25, 0.25, 0.25)
- N = (0, 0, 0.5)

推荐路径：Γ-H-N-Γ-P-H|P-N

## 六方（Hexagonal）
如：石墨烯, MoS₂, hBN

高对称点：
- Γ = (0, 0, 0)
- M = (0.5, 0, 0)
- K = (1/3, 1/3, 0)
- A = (0, 0, 0.5)
- L = (0.5, 0, 0.5)
- H = (1/3, 1/3, 0.5)

推荐路径：Γ-M-K-Γ-A-L-H-A|L-M|K-H

QE 输入示例：
```
K_POINTS {crystal_b}
4
0.0000  0.0000  0.0000  30  ! Gamma
0.5000  0.0000  0.0000  30  ! M
0.3333  0.3333  0.0000  30  ! K
0.0000  0.0000  0.0000  1   ! Gamma
```

## 简单立方（SC）
高对称点：
- Γ = (0, 0, 0)
- X = (0, 0.5, 0)
- M = (0.5, 0.5, 0)
- R = (0.5, 0.5, 0.5)

推荐路径：Γ-X-M-Γ-R-X|M-R

## 简单四方（Tetragonal）
高对称点：
- Γ = (0, 0, 0)
- X = (0.5, 0, 0)
- M = (0.5, 0.5, 0)
- Z = (0, 0, 0.5)
- R = (0.5, 0, 0.5)
- A = (0.5, 0.5, 0.5)

推荐路径：Γ-X-M-Γ-Z-R-A-Z|X-R|M-A

## 使用 ASE 自动获取 K 点路径

```python
from ase.dft.kpoints import bandpath
from ase.build import bulk

# 自动获取晶体的高对称路径
atoms = bulk('Si')
path = bandpath(atoms.cell, npoints=100)
print(path)  # 输出推荐路径
```
