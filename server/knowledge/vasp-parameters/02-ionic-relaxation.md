# VASP INCAR 参数：离子步/结构优化

来源：VASP Wiki (https://www.vasp.at/wiki/) — GNU FDL 1.2

## NSW — 离子步最大步数

**默认值**: 0（不进行离子步更新）

NSW 控制结构优化或分子动力学的最大离子步数。

**推荐值**:
| 计算类型 | NSW | 说明 |
|----------|-----|------|
| 单点 SCF | 0 | 不需要离子步 |
| 结构优化 | 50-200 | 视体系大小 |
| slab 弛豫 | 100-300 | 表面弛豫通常需要更多步 |
| 分子动力学 | 1000+ | 由模拟时间决定 |

---

## IBRION — 离子更新算法

**默认值**: -1（NSW=0 时）或 0（NSW>0 时）

| IBRION 值 | 算法 | 适用场景 |
|-----------|------|---------|
| -1 | 不更新离子 | 单点 SCF |
| 0 | 分子动力学 | MD 模拟 |
| 1 | 准牛顿法（RMM-DIIS） | 接近平衡位形的优化 |
| 2 | 共轭梯度（CG） | 初始结构较差时推荐 |
| 3 | 阻尼分子动力学 | 困难体系/高度应变结构 |
| 5 | 有限差分法计算力常数 | 声子频率计算 |
| 6 | 有限差分法 + 对称性 | 声子频率（推荐） |
| 7 | DFPT 微扰计算 | 密度泛函微扰论 |
| 8 | DFPT + 对称性 | DFPT（推荐） |

**推荐选择**:
- **一般结构优化**: `IBRION = 2`（CG，最稳定）
- **接近平衡的精细优化**: `IBRION = 1`（准牛顿法，收敛更快）
- **困难体系**: `IBRION = 3` + `POTIM = 0.1-0.5`
- **声子计算**: `IBRION = 6` 或 `IBRION = 8`

---

## ISIF — 应力/弛豫控制

**默认值**: 2（仅优化离子位置）

ISIF 控制哪些自由度被优化：

| ISIF | 离子位置 | 晶胞形状 | 晶胞体积 | 应力张量计算 |
|:----:|:-------:|:-------:|:-------:|:----------:|
| 0 | ✅ | ❌ | ❌ | ❌ |
| 1 | ✅ | ❌ | ❌ | trace 仅 |
| 2 | ✅ | ❌ | ❌ | ✅ |
| 3 | ✅ | ✅ | ✅ | ✅ |
| 4 | ✅ | ✅ | ❌ | ✅ |
| 5 | ❌ | ✅ | ❌ | ✅ |
| 6 | ❌ | ✅ | ✅ | ✅ |
| 7 | ❌ | ❌ | ✅ | ✅ |

**推荐选择**:
- **固定晶格优化原子位置**: `ISIF = 2`（最常用）
- **完全弛豫（体相晶格常数优化）**: `ISIF = 3`
- **slab 模型**: `ISIF = 2`（**禁止 ISIF=3**，真空层会坍缩！）
- **EOS 体积扫描**: `ISIF = 7`（仅缩放体积）

---

## EDIFFG — 离子步收敛判据

**默认值**: EDIFF × 10

| EDIFFG 值 | 含义 | 说明 |
|-----------|------|------|
| > 0 | 能量收敛（eV） | 连续两步能量差 < EDIFFG |
| < 0 | 力收敛（eV/Å） | 所有原子最大力 < |EDIFFG| |

**推荐**:
- 一般结构优化: `EDIFFG = -0.02`（力 < 0.02 eV/Å）
- 高精度: `EDIFFG = -0.01`
- 粗优化: `EDIFFG = -0.05`
- **推荐使用负值**（力判据），因为能量判据可能在鞍点误收敛

---

## ISPIN — 自旋极化

**默认值**: 1（非自旋极化）

| ISPIN | 说明 |
|:-----:|------|
| 1 | 非自旋极化 |
| 2 | 自旋极化 |

**何时使用 ISPIN = 2**:
- 含磁性元素（Fe, Co, Ni, Mn, Cr 等过渡金属）
- 反铁磁序
- 自由基/开壳层分子
- 缺陷态计算

**注意**: ISPIN = 2 时通常需要配合 MAGMOM 设置初始磁矩

---

## MAGMOM — 初始磁矩

**默认值**: NIONS × 1.0（ISPIN=2 时）

为每个原子指定初始磁矩。格式示例：

```
# 2 个 Fe 原子，初始磁矩各 5 μB
MAGMOM = 2*5.0

# 4 个 Fe + 4 个 O，Fe 磁矩 5，O 磁矩 0
MAGMOM = 4*5.0 4*0.0

# 反铁磁：2 个 Fe 上旋 + 2 个 Fe 下旋
MAGMOM = 2*5.0 2*-5.0
```

**常见初始磁矩参考值**:
| 元素 | 初始 MAGMOM | 说明 |
|------|:---------:|------|
| Fe | 5.0 | 高自旋 d⁶ |
| Co | 3.0 | 高自旋 d⁷ |
| Ni | 2.0 | d⁸ |
| Mn | 5.0 | 高自旋 d⁵ |
| Cr | 5.0 | 高自旋 d⁴ |
| O | 0.0-0.6 | 一般不磁性 |

**注意**: MAGMOM 原子数必须与 POSCAR 总原子数一致！

---

## POTIM — 离子步步长

**默认值**: 0.5

- IBRION=1,2: 初始步长标度因子（无量纲）
- IBRION=0,3: MD 时间步长（fs）

**推荐**:
- CG 优化: `POTIM = 0.5`（默认通常可以）
- 准牛顿法: `POTIM = 0.3-0.5`
- 困难体系: `POTIM = 0.1-0.2`
- MD: `POTIM = 1.0-2.0`（取决于最轻元素）

---

## LWAVE / LCHARG — 波函数/电荷密度输出

**LWAVE 默认值**: .TRUE.（输出 WAVECAR）
**LCHARG 默认值**: .TRUE.（输出 CHGCAR / CHG）

| 参数 | 说明 | 何时设 .FALSE. |
|------|------|---------------|
| LWAVE | 写 WAVECAR | 不需要续算时（节省磁盘） |
| LCHARG | 写 CHGCAR | 不需要续算或电荷分析时 |

**重要**: 能带计算（ICHARG=11）需要先前 SCF 的 CHGCAR，所以 SCF 步必须 `LCHARG = .TRUE.`
